# 云栖码梦 — 适老化 AI 辅助智能体

面向老年人数字办事难题，支持方言语音交互、手机截图解析、语音播报回答，用动画图片替代复杂文字，帮助老年人自主使用智能手机和线上便民服务。

## 1. 项目简介

本项目面向老年人智能设备操作困难、线上医保挂号等便民业务难以办理的数字困境，依托开源生态搭建适老化 AI 辅助智能体。

项目对开源技术开展场景化二次开发：基于开源通义千问模型完成老年场景微调，优化通俗化内容输出逻辑；改造开源 PaddleOCR 模型，提升手机低清截图、小字界面的识别效果；依托 LangChain 框架构建轻量化 RAG，搭建涵盖手机操作、便民办事、老年生活常识的专属知识库。

系统设置三大功能模块：智能手机操作教程、便民办事流程科普、老年生活基础科普，支持文字输入、语音输入（语音转文字）、手机截图解析三种交互方式，并提供语音播报（文字转语音）朗读回答，输出极简易懂的操作步骤。

项目采用前后端分离架构，前端实现适老化交互，放大字体、精简操作、大按钮设计。项目融合 AI 技术与开源二次开发成果，帮助老年人自主办理线上便民业务，降低数字服务使用门槛，助力老年群体融入数字生活。

## 2. 核心功能

### 三大知识模块

1. 智能手机操作教程：微信聊天、调大字体音量、连 WiFi、拍照发照片、防诈骗提醒等
2. 便民办事流程科普：医保挂号、社保查询、医院预约、火车票购买、社区办事等
3. 老年生活基础科普：用药提醒、健康常识、居家安全、防跌倒、日常饮食等

### 三种输入 + 一种输出

- 文字输入：大字体输入框，支持自然语言提问
- 语音输入：语音转文字，支持普通话和方言
- 手机截图解析：上传操作卡住的界面截图，自动识别并讲解下一步
- 语音播报：文字转语音，大声朗读回答，听不清可重复播放

回答要求：步骤极简、语言通俗、一次只讲一件事，优先给 3-5 步操作。

## 3. 技术方案

- 大模型：开源通义千问 Qwen，针对老年场景做指令微调，控制输出口吻通俗、步骤简短
- OCR：开源 PaddleOCR 做二次开发，针对手机低清截图、小字、反光、倾斜做图像增强和后处理
- 知识库：LangChain + ChromaDB 构建轻量化 RAG，知识分为手机操作、便民办事、生活常识三类
- 后端：FastAPI 提供统一问答接口
- 前端：适老化页面，大字体、大按钮、高对比、操作流程不超过 3 次点击
