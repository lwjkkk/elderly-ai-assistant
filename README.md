# 基于 RAG 的适老化健康与数字生活智能体

> 团队：云栖码梦 | 参赛编号：AIC-2026-44306158
> 本分支 `main` 是完整项目：后端 FastAPI + 前端 Flutter 双端 App。

面向老年人的 AI 健康助手与数字生活辅助 App。支持用药提醒与打卡、体征记录、体检报告 OCR 识别与解读、AI 问事（老人简版/家属详版）、急症双级预警、语音转写、家属端协同。

---

## 一、核心功能

### 1.1 健康管理

| 功能 | 说明 |
|---|---|
| 💊 用药管理 | 录入药品、设置服药时间、前端本地定时通知、到点后60分钟内可打卡、家属同步查看 |
| 📊 体征记录 | 血压、血糖、心率、体重录入，趋势曲线图，PDF 导出 |
| 📄 体检报告 | 上传体检单照片，PaddleOCR 结构化识别 + AI 适老解读（仅科普，不做诊断） |
| ⚠️ 急症预警 | 本地规则快速命中 + Qwen 限时语义筛查兜底，红色紧急提醒 + 120引导 + 家属端异常同步 |
| 🎙️ 语音转写 | 录音上传后端 ASR（qwen3-asr-flash），用户确认后提交，不依赖设备系统语音 |

### 1.2 数字生活辅助

| 功能 | 说明 |
|---|---|
| 📱 手机操作教程 | 微信、支付宝、手机设置等操作步骤详解 |
| 🏥 便民办事科普 | 医保挂号、社保查询、火车票购买、证件办理等流程指引 |
| 📚 生活常识问答 | 健康饮食、居家安全、防诈骗、防跌倒等科普 |
| 🔍 AI 问事 | 文字输入提问，老人简版大字回答 + 家属详版详细回答，底部附知识库来源卡片 |

### 1.3 双角色体系

| 角色 | Tab |
|---|---|
| 👴 老人端 | 用药提醒、AI问事、家人互动、个人中心 |
| 👨‍👩‍👧 家属端 | 健康总览、AI问事、家人互动、个人中心 |

家属通过邀请码绑定老人后，可远程查看健康数据、接收异常事件同步。

## 四、快速开始

### 4.1 后端运行

```bash
pip install -r requirements.txt
python scripts/init_db.py          # 初始化数据库
uvicorn main:app --host 0.0.0.0 --port 8000
```

API 文档：http://localhost:8000/docs

### 4.2 前端构建

```bash
cd app_flutter
flutter pub get
flutter build apk
```

### 4.3 后端服务

已部署云服务器：http://47.93.97.48:8000
