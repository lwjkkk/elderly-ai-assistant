## 撤回方式

只撤回目录迁移及导入调整，保留历史：

```powershell
git status --short
git revert 607c4b5
```

执行前先保存未提交改动。维护说明另有独立提交，若要连同本轮文档一起恢复，先找到并撤回该文档提交，再撤回 `607c4b5`：

```powershell

# 先 git revert 对应的 docs(frontend) 提交，再 git revert 607c4b5。
```

无需重置 `main`、删除旧分支或强制推送。此前配色、页面目录整理和云端打包修复均在检查点之前，撤回本轮整理会保留这些工作。
