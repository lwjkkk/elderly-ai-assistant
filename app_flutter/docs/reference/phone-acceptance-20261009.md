## 一、测试环境准备

### 1.1 硬件要求
- 测试手机 2 台（Android 8.0 以上，建议一台老人用大屏手机、一台普通手机）
- 两台手机连接同一 WiFi，或确保能访问后端公网地址

### 1.2 软件要求
- 后端服务已启动并可通过手机访问（http://后端IP:8000 或 cpolar 地址）
- 前端 APK 已打包，API_BASE 指向正确的后端地址
- Ollama 服务已启动，qwen2:7b 模型已拉取（用于 AI 问答和自动提取）

## 六、注意事项

### 6.1 测试前检查
- [ ] 后端服务已启动，手机可访问
- [ ] Ollama 服务已启动，qwen2:7b 模型已拉取
- [ ] APK 已安装到两台测试手机
- [ ] 两台手机时间同步
- [ ] 测试账号已准备好（或可注册）
- [ ] 手机已授予相机、麦克风、通知权限

### 6.2 测试中注意
- 每测完一个用例，立即填写"实际结果"
- 发现 Bug 立即截图，标注用例编号
- 两人协作时，通过微信群实时同步操作（如"我录了一条血压，你看看"）
- 端到端联调用例必须两人同时操作
- 遇到崩溃/ANR，立即记录复现步骤和手机型号

### 6.3 测试后整理
- 汇总所有测试用例通过/失败情况
- 更新 Bug 表状态
- 编写测试总结（通过率、遗留问题、风险评估）
- 同步测试结果到群里和 GitHub
