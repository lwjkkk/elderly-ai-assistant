# B：体检报告OCR前端配合清单（今日合并版）

最初创建：2026-10-23；本次更新：2026-10-25。本文合并今天三轮报告OCR优化及“识别失败提醒重拍”需求，作为B的统一交接入口。A本轮只改后端，未修改前端、未打APK。已实现的前端功能只需回归，不要重复开发。

## 一、后端完成范围与前端现状

后端已经加入表头驱动配对、双栏/多表与单项目表、字段独立校验、单位多视图核对、粘连数字局部恢复、疑似漏项提示，以及方向/裁剪/透视候选和原图坐标映射。候选有明确改善且不改变原先已核对数值、单位与范围时才采用；处理版本为report-ocr-2.2，字段解析版本为3.0.0。PP-StructureV3、模型微调、纸面弯曲矫正和混合方向分区识别没有完成。

本地现有report_details.dart已经支持数字/字符串结果、range_text、待核对、warnings和原文证据；这些主要做回归。下面的失败弹窗和新状态接入需要B检查补齐。

## 二、P0：识别失败后的重拍弹窗

### 同步上传

POST /api/reports/upload在识别证据不足时返回HTTP 422：

```json
{"detail":"本次未能可靠识别报告，请重新拍摄清晰、完整的报告图片。原因：……","code":"report_retake_required","retake_required":true,"retake":{"required":true,"message":"……","reasons":[{"code":"no_table","message":"未能定位报告表格"}],"requirements":["一次拍摄一页报告……"]},"quality_summary":{"detected_metrics":0,"clear_aligned_results":0}}
```

旧的detail仍为可直接显示的字符串。网络错误、服务器故障、图片格式错误不等同于retake_required，不要统一要求用户重拍。

### 异步任务

GET /api/reports/jobs/{job_id}返回status=failed、error、retake_required=true及retake；ocr_details内也保存原因和核对摘要。report为null，不生成正式报告，也不会调用Qwen解读。失败任务可能保留少量候选指标，仅供核对，不能显示“报告处理成功”。

### B需要完成

- [ ] 统一接入同步422和异步failed/retake_required，弹窗标题“识别未完成，请重新拍摄”，内容使用retake.message及requirements。
- [ ] 按任务ID/本次上传标识只弹一次，避免轮询、页面重建和打开历史时重复弹窗。
- [ ] 提供“重新拍摄”和“重新选择图片”，关闭弹窗后也能回到上传入口；不强制重复打开摄像头。
- [ ] 弹窗展示：一次一页、完整表头及结果/单位/参考条件、摆正铺平、镜头正对、均匀光线、无反光遮挡、对焦小字、上传原图。原件本身没有的字段不要求用户补造。
- [ ] recognition_status=partial时只提示“部分项目待核对”，保留已识别内容，不弹整份失败窗口。
- [ ] 服务异常、断网、鉴权失效保留对应错误反馈；旧后端没有新字段时兼容原有错误处理。

## 三、指标展示与证据

- [ ] status=unparsed或needs_review=true显示“待核对”；不按原始数字自行标红/标绿。
- [ ] result可为数字、字符串或null；例如阴性、A型、2+(125)、<0.2。不要强制转double；null不显示0。<0.2不显示为0.2或自动正常。
- [ ] result_text可作为“识别原文，待核对”补充，不把未知/乱码原文当成已确认数值。
- [ ] 范围优先range_text，支持单侧≥/≤；缺范围显示“未能核对”，不拼接null上下限。
- [ ] 展示verification_reason和warnings；置信度只能称为OCR分数，不能显示为医学准确率。
- [ ] coverage.complete_report_verified=false不代表整张失败，也不允许显示“整份报告全部正常”。
- [ ] coverage.findings为疑似漏项/未配对提示，可能包含分组留白，不能写成“已确认漏掉某项”；可按table_id、polygon或行范围定位查看。
- [ ] 单位多路读数、数字粘连恢复后仍有待核对标记时，保持该状态。

### 坐标版本说明

新版本coordinate_space=original_image_pixels：source_blocks、field_evidence、retry_fields.observations中的polygon均已映射回用户上传原图；crop/bbox为原图包围框，crop_polygon/bbox_polygon在变换后可定位四边形。按原图width/height计算显示缩放及留白。

processing_to_original记录处理图到原图的矩阵，processing_dimensions为处理图尺寸；alignment_diagnostics仍属于处理图调试坐标，不能直接画到原图。旧版局部裁剪坐标不能一概按新版规则画框，需按version/coordinate_space兼容。普通老人页面不展示矩阵、索引版本或调试参数。
