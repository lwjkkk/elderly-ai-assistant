# 知识库最终格式与后端接入说明

> **历史版本记录**：保留当时的实现、测试或操作说明；当前配置与操作以主分支最新运行说明和实际接口为准。

2026-10-24：基于 C 远程 main 提交 897ddcf 完成本轮修订。此前疑问表已由本轮最终内容替代，历史可从 Git 查看。

## 格式

- 203 篇 TXT，沿用现有目录、文件名、标题、关键词和问题字段。
- 元数据位于“回答：”之前，正文位于其后；单值字段不重复。
- 审核状态统一 approved，审核日期及更新时间为 2026-10-24；本轮审核方式为项目 AI 辅助内容核查，不声称专业医疗或法律认证。
- 最终文件不保留疑问点或编辑批注；不能确认的处方、具体指标、剂量、通用收费、到账时间或设备能力已改为有适用条件的说明，或移除不可靠细节。
- 来源网址仅保留官方机构或产品官方支持页面，允许多篇共用能支持其内容的同一链接。无对应官方链接的普通操作留空，不编造。
- 依据覆盖描述链接支持的范围；有链接不等于答案逐句由该机构认证，本文不宣布医学和法律专业审定。

## 后端接入

- 解析、索引和来源接口保留 source_scope；疑问等编辑元数据不混入模型上下文。
- 索引构建及混合检索、关键词降级路径统一执行审核和时效规则，pending、rejected、过期、异常日期及残留疑问不会作为参考正文使用。
- URL 空白的普通操作仍可检索，不伪造官方证据状态；带有完整审核与来源字段才标 documented_review。
- 内容指纹或索引格式版本变化会触发索引重建，部署时使用现有本地 bge 模型重建，不提交生成的向量数据库。
- 所有返回来源都是检索参考，不保证生成的每句话都是逐句引用；健康个体处方、当前急症和地区金额等边界继续生效。

## 运行范围

本轮推送 backend 分支供合并，不自动部署。云服务按用户要求保持关闭。未修改前端及用药闹钟实现；该功能仍按此前与 B 同步后的方案推进。
