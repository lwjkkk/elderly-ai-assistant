## 后端修改清单（尚未实施）

### A. OCR 模型加载与接口错误

1. `core/ocr.py`、`config/settings.py`：提供明确的 OCR_MODEL_DIR 配置，使用纯英文绝对路径放置检测、识别、方向分类模型，例如 D:/ocr_models；在 PaddleOCR 初始化中显式设置 det_model_dir、rec_model_dir、cls_model_dir，验证并规避可能的中文路径兼容问题。重启后使用真实照片复测，不只测试模型文件存在。
2. 增加 OCR 启动/健康检查：依赖、模型文件、预测器初始化及一张测试图识别均通过才标记就绪。
3. `api/drugs.py`、`api/reports.py`、`api/vitals.py`：区分无效图片、未识别到文字、模型/依赖不可用；环境错误返回可识别的服务错误，不统一伪装为“请重拍照片”。
4. 查药与报告在 OCR 为空时应停止生成，避免空资料被大模型自行补全。

### B. 体征结构化输出

1. `api/vitals.py`：将 `if "NONE" in llm_out.upper()` 改为只识别独立的失败标记；合法血压中的 VALUE: NONE 不应使整条结果失败。
2. 对 type 对应的必需字段进行结构校验；不适用字段允许为空。优先使用 JSON 对象和 Pydantic 解析，而不是依赖标签文本和子串匹配。
3. 对数值、单位、置信度进行校验；将无法确认的数据明确返回前端供用户核对，不静默填充默认值。

### C. 报告指标核对

1. `core/report_parse.py`：范围正则目前只识别 `--`，需支持常见的单横线、双横线、波浪线、中文“至”等形式；增加实际表格/单位/错行样例。
2. `core/health_llm.py`：指标未解析成功时，禁止输出“均正常”；应明确说明未能核对，并提示重新上传清晰报告或线下核对。
3. `api/reports.py`、`db/schemas.py`：建议返回已核对的指标列表与解析状态，前端据此展示正常/偏高/偏低，不只依赖模型自由文本。
4. 验收样例必须包含一个正常项和一个超出参考范围项，并验证模型解读与程序判定一致。

### D. PDF 导出（问题 4）

1. 在实际启动后端的 `D:/云栖码梦/.venv` 安装 requirements.txt 声明的 reportlab、matplotlib。当前该环境两者均缺失，导出最先在导入 reportlab 时抛出 ModuleNotFoundError。
2. `services/pdf_export.py`：中文字体加载失败后应提供真实字体回退；目前可能继续引用未注册的 ChineseFont。增加服务就绪检查并保证临时图文件在异常时也可清理。
3. `api/vitals.py`：依赖/生成失败返回明确服务错误；有数据时必须返回 application/pdf 且以 %PDF- 开头；无数据时保持明确业务提示。
4. `api/meds.py` 的 resolve_elder_id 目前拒绝家属未传 elder_id 的请求，因此家属本人区体征/报告及 PDF 无法正常使用。需要新增受权限保护的“本人数据”归属规则，允许家属读写自己，同时保留绑定老人权限检查；不能用某个绑定老人 ID 冒充本人。
5. 验收老人本人、绑定老人、家属本人三个场景的有数据导出与无数据提示。

### E. 查药历史与统一保存（问题 5）

1. 本次已修复老人明确药名查询的前端分流；此后专用接口生成的记录可由绑定家属读取。
2. 旧版本走 /api/chat 的药品问答只可能生成 chat_summaries，不能自动变成 drug_queries。本次没有编造或迁移历史用户数据。
3. 如要求所有自由问答中的查药和历史摘要都出现在查药卡片，`api/routes.py`、`core/chat_summary.py`、`api/drugs.py` 需统一记录来源，或提供兼容查询；保留来源/原始问题/摘要标记，避免把一句摘要当成完整药品说明。
4. 统一读取入口需遵守绑定权限与摘要同步隐私开关。历史内容无法可靠恢复时应明确显示为历史摘要，不能补造完整说明。

## 语音行为与验收

- 老人端、家属端 AI 问事都在新回复完整返回后按段落自动播报；现有后端不是流式响应，所以不是边生成 token 边朗读。
- 每条 AI 回复旁有浅灰色暂停/播放按钮，历史回复可手动重播；离开页面、新提问或打开麦克风时停止当前播报。
- speech_to_text 单例每次进入页面重新绑定状态/错误回调；初始化中松手会取消本次启动；停止和离页释放识别，保留已识别文字。
- 家人互动支持点击开始/停止和长按录音；提前松手不会在权限授权后偷偷继续启动录音。
- 手机问诊录音使用临时目录绝对路径；Web 使用 WAV 编码，上传带正确音频类型。家人互动 Web 音频按 URL 播放。
- Android 清单补充 TTS 和 PDF 打开应用可见性声明。
- 自动测试使用模拟语音平台，无法代替真机麦克风权限、识别服务、中文音色和外部 PDF 阅读器验收。
