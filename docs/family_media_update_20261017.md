# 家人语音与上传记录更新

## 前端行为

- 今日小贴士优先显示本人待服药提醒。此时“查看更多”进入当地天气。没有待服药提醒时，只显示定位获取的天气和穿衣信息，并隐藏“查看更多”。未授权定位或定位/天气不可用时不显示天气卡，不再默认武汉或显示通用药物提示。
- 家人互动长按话筒录音、松开发送，最长60秒。首次权限申请打断录音时提示再次长按。图片和语音必须发送至后端，轮询合并保留待发、失败消息，失败可重试。
- 录音通过登录鉴权获取字节后播放，不把手机本地路径发送给对方。已发送语音下方提供“语音转文字”，转写结果缓存并同步给绑定双方。
- 上传记录长按删除使用黑白确认弹窗，包括本人录入的用药、体征、报告、咨询录音、自己发送的家人消息及个人中心头像。不能删除家人的消息或资料。删除头像后禁止旧版头像缓存自动补传，重新上传头像会解除此标记。

## 后端

- `api/messages.py`：支持图片消息及语音文件持久化、绑定成员鉴权读取录音、消息删除、转写和重试去重。保留原有消息表，无数据库迁移。
- `core/speech_transcription.py`：按用户点击调用百炼 `qwen3-asr-flash`，复用 `DASHSCOPE_API_KEY`。可通过环境变量 `ASR_MODEL`、`ASR_BASE_URL` 覆盖模型与兼容接口地址。仅在点击转文字时调用；服务未配置或模型不可用返回明确错误，不影响原录音。接入格式参考阿里云官方非实时语音识别文档：https://www.alibabacloud.com/help/zh/model-studio/non-realtime-speech-recognition-user-guide
- `api/users.py`：增加本人头像删除。
- `api/vitals.py`、`api/reports.py`、`api/consults.py`：发布原有本地删除接口，删除本人记录及对应文件。

## 云端部署

上传 `elderly_backend_media_patch_20261017.tar.gz` 到服务器 `/root`，执行：

```bash
tar -xzf /root/elderly_backend_media_patch_20261017.tar.gz -C /root && bash /root/elderly_backend_media_patch_20261017/scripts/deploy_cloud_media_20261017.sh
```

脚本备份6个相关文件，更新消息模块、转写模块，并在其他现有云端模块中补充删除路由。保留数据库、.env、上传文件以及其他业务代码，重启后检查新增路由。失败自动回滚。部署后需公网核验与双端手机实测；模型转写测试需云端现有API Key具有对应模型调用权限。

## 验证

- 本地临时数据库接口测试：录音持久化与重试去重、绑定双方访问与未绑定拒绝、删除权限与媒体文件清理、转写结果缓存、图片持久化。
- 测试中的转写使用模拟返回，没有调用外部模型；真实识别效果需部署后验证。
