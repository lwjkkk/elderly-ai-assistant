1. 打开“知识库疑问点与来源核查表.csv”，按 P0、P1、P2 处理；CSV 可用 Excel 打开。
2. “疑问点”是待查清单，其中可能包含明确错误、缺少限制条件、地区/版本差异或仅缺依据。每项须回到原文确认；同主题文件共用的核查提示仅适用于本篇实际出现的内容。“原文待核对摘录”是辅助定位示例，不是疑问逐句对应或完整引用。
