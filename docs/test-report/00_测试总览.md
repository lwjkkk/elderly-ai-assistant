## 五、测试方法说明

- **后端回归**：隔离 SQLite + FastAPI TestClient + 真实 PaddleOCR/bge/Qwen/ASR 调用，故障注入覆盖限流/超时/无效 JSON/事务回滚；29 份原始日志带 SHA256 可追溯
- **前端测试**：flutter test 跑 widget/契约测试，验证权限隔离、报告重拍、语音输入、紧急话术等 88 个场景
- **真机测试**：Android 真机（荣耀 200 Pro）安装 Release APK，两位测试人员分别扮演老人和家属
- **RAG 对比**：同一问题分别走"纯大模型直接答"和"RAG 检索增强"两条路径，对比回答质量
- **Bug 管理**：所有发现问题登记在 Bug 记录表，含 P 级、责任人、发现/修复/验证日期闭环
